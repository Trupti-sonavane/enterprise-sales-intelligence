# Enterprise Sales Intelligence Dashboard

## Project Overview
This project analyzes sales performance using Power BI and the AdventureWorks dataset. It provides insights into sales, profit, regional performance, and product performance through an interactive dashboard.

## Objectives
- Analyze overall sales and profit.
- Compare sales performance across regions.
- Identify top-performing products and resellers.
- Analyze monthly and yearly sales trends.
- Create an interactive dashboard using filters.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- AdventureWorks Dataset
- GitHub

## Project Workflow
1. Data Import
2. Data Cleaning and Transformation
3. Data Modeling and Relationships
4. DAX Measures
5. Dashboard Development
6. Testing and Validation

## Dashboard Features
- Sales and Profit KPI Cards
- Sales by Region
- Profit by Product Category
- Month-wise Sales Analysis
- Top 10 Products by Sales
- Top 10 Resellers by Sales
- Interactive Filters
