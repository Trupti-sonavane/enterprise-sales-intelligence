# Dataset Information

## Dataset Name
AdventureWorks Sample Dataset

## Description
This project uses Microsoft's AdventureWorks sample dataset to analyze sales performance, product profitability, customer behavior, reseller performance, and regional sales.

## Tables Used
- Sales
- SalesOrder
- Product
- Customer
- Reseller
- Date
- SalesTerritory

## Data Source
Microsoft AdventureWorks Sample Databases:
https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure

## Data Preparation
Data cleaning, transformation, and shaping were performed using Power Query in Power BI.
